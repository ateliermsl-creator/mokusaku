# 木作工具箱

大木作・規矩術用的手機工具箱（PWA）。純 HTML / CSS / JS，沒有建置步驟，可離線使用。

## 功能（v0.1）

| 分頁 | 內容 |
|---|---|
| 算 尺貫混算 | `3間2尺5寸 + 120mm − 15.5mm` 直接混打，同時顯示 mm、間尺寸分、尺、m；有履歷 |
| 勾 屋根・隅木 | 寸勾配／角度／立上り÷水平長 → 玄、伸び率、隅木長玄、隅勾配；單邊水平長 → 垂木・隅木實長；配付垂木逐支長度表 |
| 弧 R・弧 | 弦長＋矢高（或半徑）→ R、中心角、弧長，並列出弦等分點的弧高 |
| 矩 對角線 | 矩形對角線、兩條對角線差 |

單位：1 尺 = 10/33 m ≈ 303.03 mm（台尺相同），1 間 = 6 尺。沒寫單位的數字當 mm。

## 開發

```bash
npm test                      # 計算核心的單元測試（node:test，不需安裝套件）
python3 -m http.server 8000   # 本機預覽 http://localhost:8000
```

- `js/units.js`：尺貫法解析與格式化
- `js/calc.js`：規矩術、弧、對角線的純計算函式
- `js/app.js`：介面
- `sw.js`：離線快取。**改了程式後把 `CACHE` 版本號加 1**，使用者才會拿到新版

## 上線（GitHub Pages）

repo 的 Settings → Pages → Build and deployment 選 Deploy from a branch，
挑要發布的分支與 `/ (root)`。完成後用手機開網址，
iPhone 用 Safari「加入主畫面」，Android 用 Chrome「安裝應用程式」。
所有路徑都是相對路徑，放在子路徑底下也能運作。

## 注意

算出的是理論值。軒先的納まり、鼻隠し、木負的削り等現場加減，需自行處理；
正式墨付け前請以現場實測與原寸図覆核。
