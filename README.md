# 日式大木作工具箱

日式大木作・規矩術用的手機工具箱（PWA）。介面為台灣用語，日文作為輔助文字。
純 HTML / CSS / JS，沒有建置步驟，可離線使用。

## 功能

首頁的「**木作計算機** `電卓`」內有四個分頁，記住上次用的分頁：

| 分頁 | 內容 |
|---|---|
| 台尺混算 `尺貫法` | 專用按鍵輸入（不跳手機鍵盤）：數字、丈・尺・寸・分・厘・間・mm・cm・m、`×√2`（裏目／對角線）、`÷√2`（角目）。可混打 `1間 + 3尺5寸 − 120mm`。即時顯示「**同步換算**」：公制（mm／cm／m）、尺貫法（尺・寸・分・厘，1 尺 = 10/33 m）、曲尺裏目（角目、對角線、丸目） |
| 魯班尺 `字位檢核` | 獨立分頁，有自己的長度輸入與數字按鍵。門公尺（八字）、丁蘭尺（十格）的字位條、吉凶判定、最小微調建議（可一鍵套用）、**附近的吉位區間**（目前長度 ±20／50／100／200 mm 內）、字位對照表；一循環的長度版本可選 |
| 屋頂坡度 `勾配・隅木` | 坡度（寸）／角度／立上高÷水平長 → 斜長、伸長率、角梁長弦、角梁坡度；單邊水平長 → 椽木與角梁實長；椽木逐支遞減長度表。附屋頂剖面、角梁關係、配付垂木平面三張圖 |
| 弧線半徑 `R・矢高` | 弦長＋弧高（或半徑）→ R、中心角、弧長，並列出弦等分點的弧高。附分點圖與 R、c、h 概念圖 |
| 對角線 `矩出し` | 矩形對角線、兩條對角線差（抓直角檢查，不一樣長時圖會放大歪斜）、3-4-5 法 |

所有圖示都會跟著輸入的數字改變比例，沒有數字時畫示意圖。

輸入方式：台尺混算與魯班尺用專屬按鍵面板；屋頂坡度、弧線半徑、對角線的長度欄位是「數字 + 單位下拉（丈・間・尺・寸・分・mm・cm・m）」，只要輸入數字；欄位裡直接打完整算式（如 `3尺5寸`）也可以。

### 曲尺裏目與魯班尺的依據與限制（魯班尺與台尺混算無關，是獨立分頁）

- **角目（裏目）**：刻度間隔是表目的 √2 倍，量圓材直徑直接讀出可取的方材邊長，讀數 = 長度 ÷ √2；**丸目**：讀數 = 長度 × π。
- **門公尺（文公尺）**：八字「財病離義官劫害本」，紅字（吉）為財、義、官、本；一循環約 42.9 cm，也有 46.08 cm 等版本，可在面板切換。
- **丁蘭尺**：十格「丁害旺苦義官死興失財」，吉為丁、旺、義、官、興、財；約 39.0 cm（1.28 尺 ≈ 38.8 cm）。依資料用於陰宅；家具、神位多用門公尺。
- 每個大字底下的小字（雙紅字）查不到可靠字位表，**尚未收錄**，目前只判斷到大字層級。丁蘭尺字的排列順序未逐字查證。
- 落點離字位邊界不足 2 mm 時標示「邊界」，建議值是「最小調整、且落入穩妥區」，並會實際驗證。吉凶屬民俗傳統，僅供參考。

### 台日大木作名詞＆構架對照庫

日本、台灣傳統、現場行話（台語音、日語外來語）、機能與差異「四維」對照。

- **名詞對照**：輸入日文、假名、中文或現場講法即可查，目前 134 條。可選「日文→台灣」（只比對日文，答案顯示台灣說法）或「台灣→日文」（只比對台灣用語與現場行話，答案顯示日文），卡片會把你輸入的那一邊淡化、答案那一邊反白。每條標示可信度。
- **同名異義警示**：例如日式「束」是垂直短柱，台式「束」依資料是水平聯繫構件。
- **仕口・継手 比例速查**（首頁 → 仕口・継手 比例速查）：選追掛大栓継ぎ（犁壁榫）、鎌継ぎ（蛇頭榫）或腰掛蟻継ぎ（燕尾榫），輸入材成（可用台尺鍵盤，例如 4 寸）就算出各部尺寸並畫平面、側面示意圖。比例取自《古蹟木作修復技術》V-2 圖 17 括號內的材成倍數（材成 120 mm 時與文獻標註完全一致）；栓的位置等文獻未標數字之處，圖上為目測示意並在頁面說明。金輪継ぎ、大入れ臍等尚無可查證比例，未收錄。
  追掛大栓継ぎ另有 **3D 旋轉檢視**（three.js，需要時才載入；單指旋轉、雙指縮放、拆開、沿材寬剖切）。栓孔本身未建模，界線小斜度與栓位置為目測；鎌継ぎ、腰掛蟻継ぎ的 3D 之後再加。three.js 放在 `lib/`（MIT 授權）。
- **構架圖鑑**：三張可點選的剖面示意圖，各有獨立說明：**和小屋**（束立式）、**洋小屋**（桁架：陸梁、合掌、真束、方杖、吊束）、**台式抬樑**（三通五瓜）；和小屋與洋小屋另有差異對照表（受力、構件、水平穩定、來源）。點構件顯示對照卡。
- **同名不同力**：和小屋的「束」是受壓短柱，洋小屋的「真束」是受拉吊桿，詞條與圖都有警示。
- **與計算機聯動**：垂木、隅木、勾配的卡片可直接前往屋頂坡度計算。
- **我的詞條**：可新增、刪除自己的說法（存在手機裡），並用「複製我的詞條」匯出 JSON，方便併入內建詞庫。

可信度：**已查證**（附來源）、**常見對應**（業界一般對應，未逐項查證）、**待確認**（兩邊構造不同、說法因人而異，或我無法查證）。
「已查證」現有 35 條：垂木、ほぞ、蟻継ぎ附網址；其餘依據《古蹟木作修復技術》V-2「日式木構造與修復」（陳嘉基、陳柏年，民國 102 年），卡片上標「📖 出處」與章節／圖號。
這份文獻是**台灣修復實務對日治時期日式木構造**的用語（例：土台＝木地檻、真束＝正同柱、合掌＝人字大料、陸梁＝水平大料、方杖＝腰支斜角撐、追掛大栓継ぎ＝犁壁榫、鎌継ぎ＝蛇頭榫、腰掛蟻継ぎ＝燕尾榫）。
文獻**沒有**涵蓋的仍標「待確認」：傳統漢式大木（瓜筒、通樑、三通五瓜）、現場行話與台語音、桁架受力說明（標明為力學通識）、計算機公式與魯班尺。
詞庫在 `js/glossary.js`，構架圖在 `js/diagrams.js`。

另有「加到手機桌面」教學頁。

單位：1 台尺 = 10/33 m ≈ 303.03 mm（與日本尺相同）。1 丈 = 10 尺（台灣），1 間 = 6 尺（日式）。
沒寫單位的數字當 mm。

## 配色

取自一組三色的配色表：**霧面玫瑰褐 `#b5a199`**、**米黃 `#e3e0ca`**、**藍灰 `#c6cbd0`**（色碼是從配色表圖片上的標示與像素取樣核對的；第三色標示模糊，依像素判斷為偏藍的 `#c6cbd0`）。
三色都偏淺，所以文字與按鈕用的深色是由它們調暗而來：玫瑰褐調暗＝主色，藍灰調暗＝標題列與次要強調，米黃調亮＝頁面底色。深色模式則直接用原色當主色。
色票與對比度（WCAG AA，文字 ≥ 4.5；圖形色塊 ≥ 3）由 `tests/theme.test.js` 檢查，圖示 PNG 的底色也會檢查。
功能性的狀態色（吉＝紅、凶＝黑、通過＝綠、警示＝橘）刻意不跟主題走。

換圖示或配色後，執行一次 `node scripts/build-icons.mjs`（需要 Playwright）重新產生 PNG 圖示。

## 開發

```bash
npm test                      # 計算核心的單元測試（node:test，不需安裝套件）
python3 -m http.server 8000   # 本機預覽 http://localhost:8000
```

- `js/units.js`：尺貫法解析與格式化（台尺 / 日式兩種顯示）
- `js/calc.js`：規矩術、弧、對角線的純計算函式
- `js/glossary.js`、`js/glossary-search.js`、`js/glossary-ui.js`、`js/diagrams.js`：台日大木作名詞＆構架對照庫（詞庫、搜尋、介面、構架圖）
- `js/keypad.js`（按鍵輸入邏輯）、`js/luban.js`（魯班尺計算）、`js/luban-ui.js`（魯班尺分頁）、`js/four.js`（同步換算面板）、`js/figures.js`（計算機圖示）、`js/dom.js`
- `js/section.js`：角材斷面輸入解析（`120×120 mm`、`4寸角`、`4寸×5寸`），供之後的仕口・継手圖鑑使用
- `js/app.js`：介面與路由（首頁 `#/`、木作計算機 `#/calc/mix|roof|arc|diag`、對照庫 `#/glossary`、安裝教學 `#/install`；舊網址 `#/roof` `#/arc` `#/diag` 會自動導向）
- `sw.js`：離線快取。**改了任何檔案後，要同時把三處版本號加 1 並保持一致**：`sw.js` 的 `VERSION`、`js/app.js` 的 `VERSION`、`index.html` 的 `<html data-v>`，使用者才會拿到新版（`npm test` 會檢查）

## 上線（GitHub Pages）

repo 的 Settings → Pages → Build and deployment 選 Deploy from a branch，
挑要發布的分支與 `/ (root)`。完成後用手機開網址，
iPhone 用 Safari「加入主畫面」，Android 用 Chrome「安裝應用程式」。
所有路徑都是相對路徑，放在子路徑底下也能運作。

## 注意

算出的是理論值。軒先的納まり、鼻隠し、木負的削り等現場加減，需自行處理；
正式墨付け前請以現場實測與原寸図覆核。
